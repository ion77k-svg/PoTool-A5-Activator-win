# PoTool Activator A5/A6

Windows инструмент для активации iPhone 4S, iPad 2–3 и iPod touch 5 на чипах A5/A6, застрявших на экране приветствия (Hello Screen).

> [!WARNING]
> Все действия выполняются на ваш страх и риск. Разработчик не несет ответственности за потерю данных, повреждение устройства или юридические последствия.

## Возможности

- **Активация iPhone 4S / iPad 2–3 / iPod touch 5** — обход экрана «Привет» (iCloud Hello Screen) методом bookra1n
- **Проверка поддержки** — перед запуском сверяются модель и сборка iOS, неподдерживаемое устройство активировать нельзя
- **Информация об устройстве** — модель, iOS и сборка, серийный номер, IMEI, состояние активации
- **Проверка регистрации** — серийный номер должен быть зарегистрирован, иначе активация блокируется
- **Логи** — пишутся рядом с приложением

## Системные требования

- **ОС:** Windows 10 / 11
- **Подключение:** USB-кабель, компьютер должен быть доверенным для устройства
- **Интернет:** проверка поддержки устройства и списка доступных сборок
